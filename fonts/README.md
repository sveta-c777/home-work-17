Фінальний веб-проєкт - GreenShop — Інтернет-магазин кімнатних рослин.
Проект був виконаний за макетом Figma допомогою Tailwind CSS. Tailwind дозволяє швидко створювати індивідуальні дизайни за допомогою готових класів, що зменшує кількість коду та підвищує гнучкість розробки. 
Я використовувала Flexbox для побудова гнучких сіток та вирівнювання всіх компонентів сторінки.Щоб сторінки були адаптивні та коректно відображались на різних пристроях (десктоп, таблет, мобільний).
На сторінці є всі основні блоки з макета:
1. Шапка сайту.
2. Головний банер.
3. Каталог товарів.
4. Промо-блок.
5. Блог.
6. Footer.
